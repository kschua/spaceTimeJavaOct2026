# Metaphysics systems in the app code

- **Bazi / Four Pillars (八字)** — `components/Bazi/`, `lib/cmtools/EightWords.js`; includes shen sha, synastry (合婚), major/minor cycles, element distribution
- **Qi Men Dun Jia (奇门遁甲)** — `components/QiMen/`, `lib/cmtools/MysticDoors.js`
- **Yi Jing / I Ching (易经)** — `components/YiJing/`; hexagram selector, Bazi–hexagram mapping
- **Feng Shui (风水)** — `components/FengShui/`; Luo Pan （罗盘), Flying Stars （飞星), Eight Mansions （八宅), compass degrees
- **Almanac / Tong Shu (黄历/通书)** — `components/Date/Almanac`, `DayBasicQiMen`; day officers, solar terms
- **Compendium/Library titles** — `lib/cmtools/Compendium` (FourPillarsChapter, MysticDoorsChapter, FundamentalsChapter)

Not present: Zi Wei Dou Shu (紫微斗数), tarot, Western astrology.
